DOS test pattern generators for ttl2dvi. Build with Turbo C.

mdapat.c  MDA/Hercules: text patterns (solid, dither, char clock, edges) and
          Hercules graphics stripes (BGI, see the file header to link).
cgapat.c  CGA: 320x200 bars, 1px stripes and checkerboard, 16-colour text
          bars, 640x200 bars.
egapat.c  EGA: bars, stripes and checkerboard at 200 and 350 lines, bit walk
          (one signal line per bar), 64-colour sweep.
